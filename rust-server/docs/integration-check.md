# Rust 后端联调核对清单

桌面端连接 `rust-server` 后的逐项验证清单。每项通过后在 `[ ]` 内打勾；失败项记录现象（含请求 URL、返回状态码/报错信息）反馈。

## 准备

- [ ] 启动 Rust 后端：`cd rust-server && cp .env.example .env`（填入 `ACCESS_TOKEN`，可复用 `nuxt-app/.env` 的 `NUXT_ACCESS_TOKEN` 值），然后 `cargo run`
- [ ] 后端就绪日志：`[http] listening on http://0.0.0.0:3000`
- [ ] 桌面端连接页填入 `http://localhost:3000`（或远程地址）并登录成功
- [ ] 连接后桌面端无 `/disconnected` 断连提示

## 分组

- [ ] 分组列表加载：收藏 / 最近使用 / 未分组 三个系统分组恒在顶部，顺序固定
- [ ] 自定义分组显示正确（含存量数据）
- [ ] 分组卡片显示正确 `count` 与封面图（封面为最新 4 张的缩略图）
- [ ] 新建分组成功、重名报错、使用「收藏」等系统保留名报错
- [ ] 重命名分组成功；对系统分组操作重命名/删除被拒绝（403 提示）
- [ ] 删除含表情的分组被拒绝（提示先移动或删除）

## 表情

- [ ] 上传 PNG/JPEG/GIF/WebP 均成功，生成缩略图
- [ ] GIF 上传后缩略图正常（动图原图保留动画）
- [ ] 上传超过 20MB 的文件被拒绝并显示原因，不影响同批其他文件
- [ ] 无分组上传自动落入「未分组」
- [ ] 表情网格无限滚动翻页正常（默认每页 48）
- [ ] 收藏切换即时生效，收藏分组内可见
- [ ] 复制表情后进入「最近使用」分组（上限 50），排序按使用时间倒序
- [ ] 删除表情后文件与缩略图均被清理
- [ ] 批量移动 / 批量删除正常

## 实时同步（多端验证）

- [ ] 双端（两个桌面实例或桌面端+浏览器）同时连接，一端新增/删除/收藏，另一端自动刷新
- [ ] 断线重连后自动补齐离线期间的变更

## 鉴权与安全

- [ ] 未登录访问 `/api/groups` 等受保护接口返回 401
- [ ] 错误访问密钥登录返回 401；连续 6 次错误登录被限流（429）
- [ ] 图片 URL 带 `?token=` 可访问，不带 token 返回 401

## 其他

- [ ] 总览页（dashboard）统计数字正确（表情总数/收藏数/分组数/存储占用）
- [ ] 设置页服务器连接状态显示「在线」与延迟
- [ ] 关闭/重启后端，桌面端心跳进入 `/disconnected` 页并在恢复后自动返回
